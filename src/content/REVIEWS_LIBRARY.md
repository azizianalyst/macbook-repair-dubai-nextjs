## How to use this file on the site

### For the Reviews page
Show all reviews with full text, star rating, reviewer info, date, and owner response where present. Link each to Google review page.

### For service-specific pages
Filter and show reviews that mention that service. Example: MacBook screen repair page shows reviews mentioning "screen", "cracked", "display". Use 3–6 per page.

### For the homepage carousel
Pick 8–10 best reviews (longest, most detailed, featured customer). Rotate.

### For the About / Team page
Feature reviews that mention specific technicians by name (Shafiq, Usman, Ali, Waseem). Builds personal trust.

### For multilingual pages (future)
Highlight Russian, German, French, Turkish reviews on those language versions.

### Technical implementation

Build a `<ReviewCard>` component that takes:
```ts
{
  name: string
  profile: string          // e.g. "Local Guide · 33 reviews"
  stars: 5
  date: string             // e.g. "14 weeks ago" or "17 Apr 2025"
  text: string
  ownerResponse?: string
  googleUrl: string        // link to the actual Google review
  language?: string        // for filtering
  serviceTag?: string[]    // for filtering
}
```

Build `<ReviewGrid>`, `<ReviewCarousel>` and `<ReviewFilter>` on top of this.

Load reviews from this file as MDX or JSON. Single source of truth.
