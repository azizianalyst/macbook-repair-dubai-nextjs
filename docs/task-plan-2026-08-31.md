## Cluster 2 — Price migration (8 batches) 🔴 gates deploy

**1,007 leaks across 120 files.** The site is currently in a worse state than either end point: metadata promises a quote while 120 view files still show figures.

Batched by device cluster so each batch is one coherent review:

| # | Batch | Files |
|---|---|---|
| 2.1 | MacBook (generic services) | 42 |
| 2.2 | MacBook Pro | 19 |
| 2.3 | Mac (cross-device) | 14 |
| 2.4 | MacBook Air | 12 |
| 2.5 | Mac Studio | 8 |
| 2.6 | Mac mini | 8 |
| 2.7 | Mac Pro | 7 |
| 2.8 | Legal + `/pricing` + schema | 10 |

**How:**
- Decisions already made: strip prices everywhere including SERP; Apple comparison tables keep Apple's figure and replace ours with `PriceCTA`.
- Not find-and-replace — prices sit inside FAQ answers and accordion prose, so sentences need rewriting.
- Also ~344 numeric `price:` / `applePrice:` fields that the *text* gate whitelists but components render under "(AED)" headers.
- **2.8 is order-critical:** the `/pricing` Offer prices in `page-schema.ts` must be stripped in the *same change* that removes the visible tables — not before, or schema stops matching the page.

**Verify:**
```bash
node scripts/audit-prices-src.mjs                     # fast pre-build gate
npm run build && npx next start -p 4123               # then, in another shell:
node scripts/audit-prices-rendered.mjs http://localhost:4123 /tmp/all-routes.txt
```
The rendered gate is authoritative. It now sends a crawler UA (the proxy rate-limits 60/min) and fails when any route could not be checked.
